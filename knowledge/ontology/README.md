# Ontology fixture

This directory contains a small normalized BRSO fixture for the semantic/metadata example. In a bank deployment it is replaced by the governed BRSO ontology bundle.

Canonical IDs used by the example include:
- `brso.foundation.party`
- `brso.industry.industry`
- `brso.geography.operating.geography`
- `brso.geography.country`
- `brso.exposure.exposure`
- `brso.exposure.ead`
- `brso.foundation.date`
- `brso.foundation.currency`
